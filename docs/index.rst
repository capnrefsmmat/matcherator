matcherator
===========

The matcherator is a tool for detecting lexical, rhetorical, and grammatical
features in English text by using the part-of-speech tagging, dependency
parsing, and pattern-matching facilities provided by `spaCy
<https://spacy.io/>`_. It provides rules for detecting several sets of features,
including those based on Douglas Biber's works.
